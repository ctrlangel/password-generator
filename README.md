# Password Generator

A modern, secure, and fully responsive password generator built with HTML5, CSS3, and JavaScript, featuring a sleek neumorphic dark design and real-time password strength tracking.

## 🚀 Live Demo
Check out the live application here: 
👉 [https://ctrlangel.github.io/password-generator/](https://ctrlangel.github.io/password-generator/)

## ✨ Features
* **Customizable Length:** Easily adjust your password length from 6 to 30 characters using an interactive slider.
* **Character Options:** Toggle between Uppercase letters, Lowercase letters, Numbers, and Symbols.
* **Real-time Password Strength Meter:** Visual indicator that updates dynamically based on your password's complexity.
* **One-Click Copy:** Quickly copy the generated password directly to your clipboard.
* **Modern Neumorphism UI:** Clean, dark-mode aesthetic built with CSS variables, smooth transitions, and custom responsive layouts.

## 🛠️ Built With
* **HTML5** - Structuring the application content.
* **CSS3** - Styling, layout (Flexbox), and modern neumorphic shadows.
* **JavaScript (ES6+)** - Core logic, DOM manipulation, random character generation, and clipboard API.

## 📦 How to Run Locally
1. Clone this repository or download the ZIP file.
2. Open the `index.html` file in any modern web browser.
